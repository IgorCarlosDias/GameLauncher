# 🛡️ Política de Segurança

## Versões Suportadas

Atualmente, apenas a versão mais recente na branch `main` e a última tag de release recebem atualizações de segurança:

| Versão | Suportada |
| :--- | :--- |
| `main` / Última Release | :white_check_mark: |
| Versões Anteriores | :x: |

## Reportando uma Vulnerabilidade

Se você descobriu uma vulnerabilidade de segurança no GameLauncher:

1. **NÃO** abra uma Issue pública.
2. Utilize o recurso nativo e gratuito do GitHub **[Security Advisories](https://github.com/IgorCarlosDias/GameLauncher/security/advisories/new)** para reportar de forma privada.
3. Descreva o impacto, etapas para reprodução e possível mitigação.
4. Responderemos com prioridade e providenciaremos um patch corretivo.
